v0.9.72 fixes the reported freeze on real PS2 hardware when a battle animation reaches the first spoken line. The fix has been confirmed on the affected PS2 setup.

This release contains the full current English translation and uses the exact game image that passed the Diagnostic C hardware test. All existing font, UI, caption-rendering and other executable patches remain in place.

## Changes

- **PS2 battle freeze fixed:** battle-caption blocks now retain the original game's 16-byte alignment. The repair adds padding and updates the matching offset table, preserving the existing caption records and voice IDs. A build check now catches misaligned archives.
- **Translation updates since v0.9.68:** includes the Rey/Ray and Hugi corrections, the Stage 47 “Count Down” retranslation, restored dialogue brackets for Back Log speaker colouring, and the Kotsett/Jie/Koji Kabuto/Taikyoku consistency pass from v0.9.69–v0.9.71.
- **Latest working corrections included:** dialogue pronouns and wording, Faye Xin Lu and Teral, and battle-caption spacing and ellipses.
